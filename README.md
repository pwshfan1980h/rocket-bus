# Rocket Bus

Launch a double-decker bus off ramps, fire the rocket to clear the gap, land it level.

**Play:** https://pwshfan1980h.github.io/rocket-bus/

**Keys:** D / → drive · A / ← brake · Space rocket · F cannon · H horn · R retry · Esc pause

Made with Godot 4.7. Open the folder in Godot and press Play.
